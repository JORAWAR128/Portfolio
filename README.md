# Jorawar Singh — Portfolio

A minimalist, monochrome personal portfolio demonstrating my engineering work in Artificial Intelligence, Machine Learning, and Web Development. It serves as a centralized hub for my featured projects, technical skills, and professional certifications.

## 🌐 Live Portfolio

[https://portfolio-three-kappa-25.vercel.app/](https://portfolio-three-kappa-25.vercel.app/)

## ✨ About

This portfolio embodies an editorial, content-first design philosophy. It highlights my academic and independent work as a B.Tech Computer Science student specializing in AI & Machine Learning. The interface is intentionally stripped back to prioritize readability, structured typography, and precise interactions over unnecessary visual noise.

## 🚀 Features

- **Component-Driven Architecture**: Fully modular React component structure.
- **Editorial Aesthetics**: Custom monochrome theme with rigid geometric alignments.
- **Fluid Micro-Interactions**: Smooth reveals, hover states, and scroll transitions powered by Framer Motion.
- **Dynamic Project Previews**: Custom programmatic SVG representations and scalable image mockups.
- **Data-Driven Content**: Centralized JS data files for rapidly updating skills, projects, and certifications.
- **Responsive Layout**: Seamless scaling across desktop, tablet, and mobile breakpoints.

## ⚙️ Getting Started

Follow these steps to run the portfolio locally:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview the production build locally:**
   ```bash
   npm run preview
   ```
